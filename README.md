# Personal Portfolio Website — Nabanita Gain

## Introduction

This is my personal portfolio website developed to showcase my academic background, technical skills, software projects and career objectives. The website provides a professional platform for recruiters, teachers, students and potential collaborators.

## Features

- Responsive and multi-page website
- Common navigation menu
- Light and dark mode
- Personal introduction and career objectives
- Academic information
- Technical skills
- Project showcase and individual project details
- Internal and external hyperlinks
- Contact form with validation
- EmailJS integration

## Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- Tailwind CSS
- DaisyUI
- React Router
- Framer Motion
- EmailJS

## Website Pages

| Page | Purpose |
|---|---|
| Home | Provides an overview of the portfolio |
| About | Presents personal information and career objectives |
| Projects | Showcases completed software projects |
| Education | Displays academic qualifications |
| Contact | Allows visitors to send messages |
| Project Details | Provides detailed information about individual projects |

## Installation

1. Clone the GitHub repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Configure the required EmailJS environment variables.
5. Run `npm run dev`.
